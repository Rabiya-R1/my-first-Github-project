Electrical Engineering Toolkit 

Project Overview

The Electrical Engineering Toolkit is a Python-based application designed to perform basic electrical engineering calculations through a simple graphical user interface.

Features

- Single-phase electrical power calculation
- Three-phase electrical power calculation
- Energy consumption calculation
- Electricity bill estimation
- User-friendly graphical interface using Tkinter

Technologies Used

- Python 3
- Tkinter
- Math module

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python electrical_toolkit_gui.py

Project Files

- "electrical_toolkit_gui.py" – Graphical application
- "electrical_calculator.py" – Command-line calculator

Purpose
